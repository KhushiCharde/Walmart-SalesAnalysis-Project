Understand the analysis

How are these metrics calculated?Sales = unit price × quantity. Estimated profit = sales × supplied profit margin. Average rating is the unweighted average of recorded ratings. Revenue decline = (2022 sales − 2023 sales) ÷ 2022 sales × 100. Morning is before 12:00; afternoon is 12:00–17:59; evening begins at 18:00.
What does this deployed version do?This dashboard calculates summaries in your browser using the repository’s processed CSV data. The original project demonstrates Python preparation and SQL analysis. This dashboard does not run Python or connect to a live MySQL database. Filters and search stay in your browser.
What are the limitations?This is a learning dataset labelled as Walmart sales. Its exact original source, authenticity and completeness are not verified here. Values use the dollar-labelled currency in the source. Profit is an estimate from supplied margins, not verified accounting profit. Findings describe the dataset and do not establish causes.
DATA QUALITY · Raw file: 10,051 rows. Processed file: 9,969 records, 100 branches and 98 cities. The raw file contains 51 exact duplicate rows and 31 incomplete rows after deduplication. No live company data or forecasting is used.
